⚙️ МЕТОДЫ ПЕРЕВОДА

10→2
МЕТОД ДЕЛЕНИЯ
Из 10-чной в другую
Шаг 1: Делим число на основание новой системы
Шаг 2: Записываем остаток
Шаг 3: Повторяем с целой частью
Шаг 4: Читаем остатки снизу вверх
Лучше всего для: 10→2, 10→8, 10→16
2→10
МЕТОД РАЗЛОЖЕНИЯ
Из другой в 10-чную
Шаг 1: Записываем разряды числа
Шаг 2: Присваиваем веса (степени основания)
Шаг 3: Умножаем цифры на их веса
Шаг 4: Суммируем результаты
Универсальный метод для любой системы → 10-чная
2↔8↔16
ЧЕРЕЗ ДВОИЧНУЮ
Между 2, 8, 16 системами
2→8: Группируем по 3 бита справа
2→16: Группируем по 4 бита справа
8→2: Каждую цифру заменяем 3 битами
16→2: Каждую цифру заменяем 4 битами
Самый быстрый способ для 2,8,16 систем

📝 ПОШАГОВЫЕ ПРИМЕРЫ

ПРИМЕР 1: 29₁₀ → 2-чная система
Шаг 1: 29 ÷ 2 = 14 (остаток 1)
Шаг 2: 14 ÷ 2 = 7 (остаток 0)
Шаг 3: 7 ÷ 2 = 3 (остаток 1)
Шаг 4: 3 ÷ 2 = 1 (остаток 1)
Шаг 5: 1 ÷ 2 = 0 (остаток 1)
Читаем остатки снизу вверх: 11101₂
ПРИМЕР 2: 1011₂ → 10-чная система
Разряды: 1 0 1 1
Веса (2³,2²,2¹,2⁰): 8 4 2 1
Умножение: 1×8 + 0×4 + 1×2 + 1×1
Вычисление: 8 + 0 + 2 + 1
Результат: 11₁₀
ПРИМЕР 3: 753₈ → 2-чная → 16-чная
8→2 (каждая цифра → 3 бита):
7 = 111₂, 5 = 101₂, 3 = 011₂
Объединяем: 111101011₂
2→16 (группы по 4 бита):
0001 1110 1011 (добавляем нули слева)
Переводим: 1 = 1₁₆, 1110 = E₁₆, 1011 = B₁₆
Результат: 1EB₁₆

⚡ БЫСТРЫЕ ПРАВИЛА

ТАБЛИЦА ГРУППИРОВКИ БИТОВ
2-чная 8-чная 16-чная Правило
000 0 - 3 бита = 1 цифра 8-чной
111 7 - Максимум для 3 битов
0000 - 0 4 бита = 1 цифра 16-чной
1111 - F Максимум для 4 битов
1010 12 A Пример перевода 10₁₀
Запомните:
• 8-чная: группируем по 3 бита справа налево
• 16-чная: группируем по 4 бита справа налево
• Если битов не хватает — добавляем нули слева
