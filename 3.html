🔄 ПРАКТИЧЕСКИЕ ПРИМЕРЫ

ПЕРЕВОД 8-НОГО В 10-ЧНОЕ: 247₈
247₈ = 2×8² + 4×8¹ + 7×8⁰
= 2×64 + 4×8 + 7×1
= 128 + 32 + 7 = 167₁₀
ПЕРЕВОД 16-НОГО В 10-ЧНОЕ: 2FA₁₆
2FA₁₆ = 2×16² + F×16¹ + A×16⁰
= 2×256 + 15×16 + 10×1
= 512 + 240 + 10 = 762₁₀
